# Customer Segmentation using RFM Analysis

## Problem
Identify which customers drive the most revenue and how to retain them.

## Dataset
Online Retail II (UCI) - https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci

## Tools
MySQL, Power BI

## Approach
1. Cleaned data (removed cancelled orders, missing customers, invalid quantity/price)
2. Calculated Recency, Frequency, Monetary per customer
3. Scored each 1-5 using NTILE
4. Created segments: Champions, Loyal, At Risk, Lost, Potential
5. Built Power BI dashboard
